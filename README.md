# Scoop Arch Bucket

个人 Scoop bucket，收录常用软件与工具。

## 安装

```powershell
scoop bucket add Arch https://github.com/liarchgh/ArchBucket
```

添加后安装某个软件：`scoop install Arch/<app>`（见下表）。

## 软件列表

| 软件 | 安装命令 | 用途 |
| --- | --- | --- |
| AirtestIDE | `scoop install Arch/AirtestIDE` | 跨平台 UI 自动化测试 IDE（Airtest 官方） |
| ContextMenuManager | `scoop install Arch/ContextMenuManager` | Windows 右键菜单管理程序 |
| biliup-rs | `scoop install Arch/biliup-rs` | B站命令行投稿（支持多P）与视频下载工具 |
| fennel | `scoop install Arch/fennel` | 一种 Lisp 方言编程语言，编译为 Lua |
| ghc | `scoop install Arch/ghc` | Haskell 函数式语言编译器与交互环境 |
| KeymouseGo | `scoop install Arch/keymousego` | 鼠标键盘录制与自动化操作（类似按键精灵） |
| PasteEx | `scoop install Arch/pasteex` | 把剪贴板内容直接粘贴为文件 |
| Vidupe | `scoop install Arch/vidupe` | 视频查重：按视频内容比对相似/重复，无视格式与压缩 |
